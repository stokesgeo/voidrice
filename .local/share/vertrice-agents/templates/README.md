# Shared agent home

Your agents' continuity: tasks, handoffs, notes and session records. Human
work stays in its own project and document folders. These are starting files;
change them as you like. Personal records stay here, never in a public repo.

## Start here

Enter the project directory. Its README says what the project is; its
`AGENTS.md`, if any, says how agents work there. Check which instructions your
harness actually loads.

- **Find a way to do something:** `vertrice-agents find WORDS` finds mentions
  here; then check the tool's own help. A mention is not proof a tool works.
- **Pick up work:** `vertrice-agents task list` shows each task, its owner and
  next action. Read one by ID; follow its handoff if it has one.

Read `USER.md` or `vision.md` when relevant, not at every start.

## Places

| Path | Purpose |
| --- | --- |
| `AGENTS.md` | Shared operating instructions |
| `USER.md` | What the owner has said about themselves and their preferences |
| `vision.md` | Aims, possibilities and open questions |
| `tasks/` | Tracked work, including undecided `maybe` items |
| `plans/` | Proposed approaches, not permission to act |
| `decisions/` | Decisions with scope and source |
| `handoffs/` | Resume a thread without rereading its history |
| `reports/` | Findings, evidence and limits |
| `memory/` | Correctable facts with their sources |
| `skills/` | On-demand procedures in standard skill format |
| `sessions/` | Native session histories or supported exports |
| `archive/` | Inactive material kept for reference |

Use only what helps: a task does not need a plan, report and decision. Link
rather than copy.
