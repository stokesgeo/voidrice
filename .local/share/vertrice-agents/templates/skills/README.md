# Skills

Use the standard directory format: `skills/<name>/SKILL.md`. Begin `SKILL.md`
with YAML frontmatter containing `name` and `description`, followed by concise
instructions. State when to use it, required capabilities, boundaries and how
to verify the outcome. Add supporting files only when needed.

A skill describes a procedure; it does not install tools or grant permission.
Confirm your harness discovers this directory and supports any optional fields.
Keep secrets and personal records out of public skill source.
