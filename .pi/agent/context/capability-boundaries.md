# Capabilities and trust

Local tools cover ordinary-user files, work/context, native subagents, owner
approval, live IPE seats and UI/theme integration when their host APIs exist.
Tool names and roles are cooperative behavior, not an OS sandbox.

Crew/Messenger and Board require their separately selected source closure and
runtime integration. No campaigns, accounts, sessions, acceptance records or
stores are supplied. Preserve existing local state; do not invent migrations.

Remote search, video, corpus and other-machine interfaces are optional and
unconfigured. Use only an explicitly approved available transport. Preserve
provenance and separate retrieved text from verified facts. No secret reuse,
private-network fetching or hidden provider fallback. Transcript access is not
visual understanding; fixture and connection success are not source reading.
