# Selected local context

AGENTS.md is the operational append; native-context.md is a distinct continuity
stub. This package is reusable workflow source, not a personal corpus.
context/manifest.json names the exact text selection with SHA256 hashes.
context_search is lexical; context_read checks the exact selected path and hash.
Missing or stale bytes fail visibly. context-index.mjs refreshes only that
selection; it never discovers sources or admits private state.

resources.json separately lists packaged files and loader entrypoints. Crew and
Board also need source-owned generation integrations; naming a capability does
not install its dependencies or authorize migration of local state.
