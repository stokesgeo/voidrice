# Git boundaries

Identify the checkout, branch, remotes and staged/unstaged changes first.
Preserve unrelated work. A dotfiles repository may be bare with HOME as work
tree; confirm rather than assuming a developer checkout. Stage explicit paths,
not an entire home directory. Keep credentials, sessions and work stores out.
Save, commit and remote arrival are different outcomes. Commit/push, destructive
operations and publication require the corresponding authority; no standing
personal delivery policy is included here.
